# Demon Bazooka

Demon Bazooka is a compact 3D arcade game for the Sega Dreamcast. You are one
heavily armed human dropped into a circular hellscape while waves of devils
close in. Move, fire splash-damage rockets, dash through danger, charge the
Rocket meter and trigger a screen-clearing Bazooka Barrage before your six
lives are clawed away. Later waves bring faster imps, winged elites, tougher
archfiends and a boss every fifth wave. Everything on screen and in the
speakers is generated by the C code at startup; there are no asset files.

## Download

Download the latest **[self-booting CDI](https://github.com/richstokes/dreamcast-homebrew/releases/latest/download/demon-bazooka.cdi)**
for Flycast or CD-R. A direct-load [ELF](https://github.com/richstokes/dreamcast-homebrew/releases/latest/download/demon-bazooka.elf)
is also available.

## How to play

Slain demons sometimes drop timed powerups, and archfiends always leave one.
Pickups expire after 12 seconds if ignored; a duplicate extends the active
effect.

- Speed Boost (cyan): faster movement
- Rapid Fire (gold): more than double the firing cadence
- Triple Bazooka (magenta): every shot becomes a three-rocket spread

## Controls

- Analog stick or D-pad: move and aim
- A: fire the bazooka
- B: dash; briefly grants invulnerability
- X: Bazooka Barrage when the Rocket meter is full
- Start or A: begin or restart from the title and game-over screens
- Start + Y during play: exit to KallistiOS

Flycast normally maps the keyboard Enter/Return key to Dreamcast Start.

## Build and run

```sh
source "$HOME/.local/share/dreamcast/kos/environ.sh"
make              # demon-bazooka.elf
./run-flycast.sh  # builds first; `make run` launches an already built ELF
```
