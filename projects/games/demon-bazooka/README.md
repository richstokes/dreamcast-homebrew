# Demon Bazooka

Demon Bazooka is a compact, original 3D arcade game for the Sega Dreamcast.
You are one heavily armed human dropped into a circular hellscape while waves of
devils close in. Move, fire splash-damage rockets, dash through danger, charge
the Rocket meter, and trigger a screen-clearing Bazooka Barrage before your six
lives are clawed away.

Later waves deploy faster imps, winged elite demons, tougher archfiends, and a
boss opening every fifth wave. Slain demons occasionally drop timed powerups,
and archfiends always leave one behind:

- **Speed Boost** (cyan): faster movement
- **Rapid Fire** (gold): more than double the firing cadence
- **Triple Bazooka** (magenta): every shot becomes a three-rocket spread

Pickups expire after 12 seconds if ignored, and duplicates extend an active
effect.

Everything you see and hear is generated by C code at runtime: there are no
textures, models, fonts, or audio files. The visuals are untextured PowerVR
polygons, and the music, sound effects, and demonic speech are synthesized at
startup.

## Download

Download the latest **[self-booting CDI](https://github.com/richstokes/dreamcast-homebrew/releases/latest/download/demon-bazooka.cdi)**
for Flycast or CD-R. A direct-load [ELF](https://github.com/richstokes/dreamcast-homebrew/releases/latest/download/demon-bazooka.elf)
is also available.

## Controls

- Analog stick or D-pad: move and aim
- A: fire the bazooka
- B: dash; briefly grants invulnerability
- X: Bazooka Barrage when the Rocket meter is full
- Start: begin or restart from title/game-over screens
- Start + Y during play: exit to KallistiOS

On the title or game-over screen, press A or Start to begin or restart.
Flycast normally maps the keyboard Enter/Return key to Dreamcast Start.

## Build

Source the installed KallistiOS environment and run `make`:

```sh
source "$HOME/.local/share/dreamcast/kos/environ.sh"
make
```

This creates `demon-bazooka.elf`, a little-endian Renesas SH executable.

## Run in Flycast

```sh
./run-flycast.sh
```

The launcher builds by default. Use `make run` to run an already built ELF.
